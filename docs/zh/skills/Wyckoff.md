# Wyckoff

基于图表、带时间戳的 OHLCV，或通过共用 Polygon 接口获取的美股日线，构建可被后续证据推翻的威科夫情景。这是实验性的分析 skill，区分可观察事实、结构解释和条件计划。取数脚本不自动识别阶段，也没有校准概率模型或已经验证的盈利优势。

## 1. 输入要求

提供可读图表或按时间排列的 OHLCV、标的、周期和分析截止时间，并尽量注明来源、时区、已完成 K 线和成交量类型。也可以提供美股／ETF 代码，通过共用接口取日线。自带数据无需 API key；在线取数需要 `POLYGON_API_KEY`、Python 3.9+ 和该技能 `requirements.txt` 中的依赖。缺少成交量时可以降级为价格结构分析，但不能声称获得量价确认。

目录和 skill 名称按要求保留为大小写敏感的 `Wyckoff`。仓库的名称与目录一致性检查可通过；要求全小写的通用 skill 校验器会报命名问题。安装到仅接受小写名称的平台时，需要同时调整目录名和 frontmatter 名称。

## 2. 使用示例

> 用 Wyckoff 分析这张日线图，只使用最后一根已完成 K 线之前的信息。比较吸筹与下跌延续两种解释，列出反证、触发和失效条件，不要编造胜率。

历史回放应提供截至目标时点的数据。已经展示后续走势的完整图表只能用于回顾性解读，不能当作盲测预测。

在仓库中执行取数：

```bash
python3 skills/Wyckoff/scripts/fetch_wyckoff_data.py \
  --symbol AAPL --start 2024-01-01 \
  --as-of 2024-10-01T12:00:00-04:00 --output-dir reports/
```

日期和标的应替换为实际请求。脚本保守地排除纽约时间截止日期当天的整根日线，即使已经收盘；上述示例最多包含 9 月 30 日。当前取数入口只支持日线。追加 `--provider fixture --fixture-dir DIR` 可离线读取共用缓存格式，不联网、无需 API key。独立安装技能包时，需要把 `TRADING_SKILLS_REPO_ROOT` 指向包含 `scripts/market_data` 的仓库；技能包没有复制这套共用模块。

## 3. 分析流程

1. 确定数据来源和信息截止边界。
2. 先描述价格、振幅、收盘位置和可比较成交量，再贴结构标签。
3. 记录事件定义、发生时间、最早确认时间和候选／确认／失败状态。
4. 比较主情景与可信的替代情景。
5. 写明触发、失效和缺失证据，给出条件计划、等待、不交易或数据不足。

不强制出现 Spring 或 UTAD，不补画看不到的早期阶段。看多假设失效不自动等于派发成立；“可能存在吸收”也不等于已经识别出机构交易者。

## 4. 输出

行情分析在 `reports/` 下生成配套 Markdown 和 JSON，文件名为 `Wyckoff_<symbol>_<cutoff>_<run-id>`，保留不同版本。报告包含数据限制、事件确认时间、情景证据、触发与失效、以及相对前次判断的变化。未知数值用 null；概念问答直接回答，不生成空报告。

取数脚本另生成 `Wyckoff_ohlcv_<symbol>_<cutoff>_<run-id>.json`，包含按时间升序的日线和来源信息，供分析阶段读取。异常 OHLCV 会报错，零成交量会保留并标记。价格统一采用拆股复权 OHLC，不混入单独的股息复权收盘价；历史数据仍可能被供应商修订，因此不是严格的历史时点快照。交易日覆盖和数据是否陈旧仍需检查。退出码 0 表示成功保存数据，1 表示取数／数据／输出失败，2 表示参数或环境配置问题。

| 状态 | 含义 |
|---|---|
| `INSUFFICIENT_DATA` | 无法建立关键观察事实 |
| `WAIT` | 结构仍需进一步证据，尚不能形成有依据的计划 |
| `NO_TRADE` | 已评估的方案失效或缺乏可辩护的计划 |
| `CONDITIONAL_PLAN` | 结构证据足以支持明确条件；执行触发仍可处于待发生状态 |

证据强弱不是交易胜率。仓位计算需要另外提供风险参数；skill 不下单、不更新持仓、不发送通知。默认按仓库约定输出英文报告，用户明确指定其他语言时遵循用户要求。

## 5. 研究边界

只有请求实证验证时才加载研究流程：固定策略定义，使用当时可知的信息，保留按时间分割的样本外数据，处理事件相关性、多次试验及交易成本。人工判断可以用盲测或事前记录检验。合成图形识别率、价格触及目标位，都不能直接当作交易有效性的证据。

实现吸收了 naiemk 的情景分析思路和现代 Wyckoff 教学，补上时间与数据来源约束，重新组织为本仓库适用的内容。没有复制整套第三方书籍，也没有把币圈轮动、江恩或波浪规则强加到核心分析中。

## 6. 文件

技能包含 `SKILL.md`、四份参考文件（方法、数据与时间、研究验证、来源）、报告模板、取数脚本和 `requirements.txt`。来源与证据边界见 `skills/Wyckoff/references/sources.md`。
